# JustType — 繁體中文打字練習

輕量、無後端、解壓就能跑。不分年齡層，共 925 題。

## 模式

| 模式 | 題數 | 玩法 |
|---|---|---|
| 單字 | 494 | 常用詞，10 題一輪 |
| 短句子 | 115 | 日常短句，5 題一輪 |
| 小短文 | 30 | 106–150 字，一篇一輪 |
| 長文章 | 36 | 231–274 字，一篇一輪 |
| 生活情境題 | 40 | LINE 對話格式，一題一輪 |
| 中英雜燴 | 60 | 中英混排日常句，一題一輪 |
| 文言文 | 57 | 古文與志怪節錄，一題一輪 |
| 一般法律公文 | 45 | 一般法律＋普通公文，一題一輪 |
| 訴訟法律公文 | 48 | 程序法＋訴訟公文，一題一輪 |

## 怎麼跑

```sh
./serve.sh
# 或
python3 serve.py 8092
```

瀏覽器開 `http://127.0.0.1:8092/`。不要直接雙擊 `index.html`，`data.json` 的 fetch 在 `file://` 會被擋。

## 功能

- 逐字判定：對綠、錯紅、當前字底線提示
- 計時與結算：字／分鐘、正確率、答對字數、個人最佳，存在本機 `localStorage`
- 無盡模式（預設關閉）：不結算、自動跳下一題
- 鍵位提示：注音／倉頡／嘸蝦米／速成 四版面，一次只亮下一鍵
- 拆字提示：倉頡／嘸蝦米／速成 可切換，跟著打字進度更新
- 標點寬容：半形與全形 `, . ! ? ; :` `，。！？；：` 互通
- 注音組字期間不計分，誤入英文字母 2 個自動跳題
- 深色模式、首頁輪播選關

## 檔案

- `index.html`、`style.css`、`app.js` — 頁面、樣式與打字引擎
- `assets/` — favicon 圖示
- `data/` — 題庫與字庫：`data.json`（題庫）、`zhuyin.json`（注音對齊）、`cangjie.json`（倉頡）、`boshiamy.json`（嘸蝦米，速成由倉頡推導）
- `build_cangjie.py`、`build_boshiamy.py` — 重建拆字字庫
- `serve.py`、`serve.sh` — 靜態伺服器
- `validate_queue.js` — 抽題回歸門（`node validate_queue.js`）

## 題庫來源

- 單字、句子、小短文、長文章、生活情境、中英雜燴：原創撰寫
- 文言文：古代公有領域文本，已轉為台灣常用繁體
- 法律條文：中華民國現行法規短條文
- 公文：原創虛構範例，無真實機關、姓名與案號
