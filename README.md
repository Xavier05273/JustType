# JustType — 繁體中文打字練習（輕量版）

不分年齡層、無後端、解壓就能跑的原創重寫版。

| 模式 | 題庫 | 說明 |
|---|---|---|
| 單字 | `data.json` → `words`（494） | 一組 1–4 字常用詞，10 題一輪 |
| 句子 | `sentences`（115） | 含標點日常短句，5 題一輪 |
| 小短文 | `articles_punct`（104） | 完整標點段落 |

題庫來源：ungraded 池（494/115/65/65）合併先前擴充的成人長文 39 篇（前兩篇標題在原文為技術類，另有「城市的清晨」「公園長椅」等），去重後三池為 494 / 115 / 104。

> 介面與打字引擎為原創撰寫（非抄 TypeMate 版面），只對齊「三分類＋逐字判定＋計時＋結算」的功能。

## 怎麼跑

```sh
./serve.sh            # http://127.0.0.1:8092/
# 或
python3 serve.py 8092
```

直接雙擊 `index.html` 也能看版面，但 `data.json` 的 fetch 在 `file://` 會被瀏覽器擋，所以請用上面 serve。

## 行為（與 TypeMate 的對齊點 / 有意改進）

- 計時從按下鍵或注音輸入起算；選字期間即時計時，選完逐字判定對錯。
- 首頁關卡選擇改為 3D 旋轉木馬（coverflow）：中央卡片平貼放大，兩側卡片依距離自動 ±42° 內轉、後退並淡出；支援拖曳慣性、滾輪、導航箭頭（‹ / ›）、下方圓點與方向鍵切換，點正中央卡片開始挑戰；正中央卡片帶頂部光源高光掃過、圖層永遠在最上層。
- 打字介面下方可勾選「鍵位提示」：輸入框下方出現與真實物理鍵盤 1:1 排列的螢幕鍵盤（採標準 ANSI 5 排鍵位與標準交錯寬度：注音版面採台灣標準排列，鍵面上方顯示注音符號與聲調、下方顯示實體鍵如 1/Q/A），包含完整修飾鍵與空白鍵；勾選狀態和版面存在 `localStorage`，下次自動記住。
- 鍵位提示動態偵測當前目標字：系統即時偵測目前打到哪個字，動態至字庫（`zhuyin.json` 包含 41,000+ 繁體漢字庫與常用詞庫）查詢該字的注音，將注音符號與聲調逐一映射到實體鍵盤對應鍵位；提示一次只亮**下一鍵**（不顯示 1/2/3 數字順序），注音打到哪裡就跟到哪裡，已打鍵變綠、下一鍵高亮（例如「躺」先亮 ㄊ(W)，打完後才亮 ㄤ(;)，再來是 ˇ(3)；一聲字最後亮空白鍵）。實作上會先把 `input` 事件的整盒值切掉已打字前綴只比對當前字段，避免第一個字的注音一直重複；標點符號與英文亦動態對應實體鍵位與 Shift 提示。完全擺脫寫死的題庫對應表，適用於任何文章與詞彙。
- 拆字提示：練習頁目標文字**右上角**一律顯示目前要打的字之拆字，**倉頡／嘸蝦米／速成三個完整方塊做成橫向反向環滾輪**（整顆小長方形，中央顯示目前選中的輸入法如「倉頡 一：一 m」／「嘸蝦米 一：E」／「速成 一：一 m」；拖曳、滾輪、點側邊方塊或點左右箭頭切換，選擇存在 `localStorage`，下次自動記住；角度與首頁 coverflow 反向：首頁 `rotateY(-off*42°)` 平面排，這裡 `rotateY(+off*26°)` 配 sin/cos 圓柱投影繞環往後收），隨打字進度即時偵測更新，不依賴「鍵位提示」勾選；標點/英數顯示「照打」、字庫未載入或查無拆字亦有明確提示；組字時整顆滾輪凍結不跳動（送出後才換下一字）。字庫 `cangjie.json`（41,857 字）由 `build_cangjie.py` 依 Jackchows/Cangjie5 `Cangjie5_TC.txt`（倉頡五代、台灣用字優先，MIT License）產生，範圍與 `zhuyin.json` 的 chars 平行，每字取碼表首選碼；`boshiamy.json`（13,076 字）由 `build_boshiamy.py` 依 chinese-opendesktop/cin-tables `boshiamy.cin`（行易嘸蝦米碼表，非商業授權）產生，每字取最短碼，題庫漢字覆蓋 1460/1464（未覆蓋僅標點/省略號）；**速成**沒有獨立字庫，由倉頡碼即時推導（3 碼以上取首碼＋尾碼，如謝 `yrhhi`→速成 `yi`，半 `fq` 不變）。重跑 `python3 build_cangjie.py` / `python3 build_boshiamy.py` 即可更新。已用維基百科範例交叉核對（謝倉頡 `yrhhi`、嘸蝦米 `isa`）。
- 鍵位提示版面：版面下拉（注音／倉頡／嘸蝦米／速成）。倉頡鍵面主字為字根（A=日 … Y=卜，X=難，Z=重）、副字為英文字母；嘸蝦米／速成鍵面只顯示大寫英文字母（不要漢字部首），空白鍵副字為「選字」；逐步高亮規則同注音（一次只亮下一鍵、已打變綠，最後亮空白鍵「選字」）；已打進度由組字區字母反推，IME 不把 preedit 放進輸入值時停在首鍵、送出後自動跳下一字。原「英數（QWERTY）」選項已改名為「嘸蝦米」，舊選擇會自動對應過去。
- 小短文亦有「無盡模式」，**預設關閉**：勾選後不結算彈窗、持續自動跳下一題（標題顯示「· 無盡」），未勾選維持原本每篇結算彈窗；與單字／短句子一樣依模式存於 `localStorage`。
- 單字 10 題一輪、句子 5 題一輪：輪中自動跳下一題不彈窗，第 10／5 題完成輸入框才結算（整輪累積用時、正確率、答對字數與個人最佳）；勾選下方「無盡模式」則不結算，持續自動跳下一題。
- 單字與句子在無盡模式（及小短文）仍可用「自動跳下一題（不彈窗）」決定是否每題彈窗；有限輪的中途題不受該勾選影響，輪滿一律結算。
- 單字模式提供「英文輸入法保護」：誤鍵入 2 個英文字母即判定為未切換輸入法，自動跳下一題並不計入異常紀錄。
- 支援深色模式（Dark Mode），自動跟隨系統偏好，右上角可一鍵切換深淺色並記憶於本機（按鈕顯示目前主題：淺色為 ☀️淺色、深色為 🌙深色）。
- 線性卡片式（Cards/Grid）：首頁三張挑戰卡各自有顏色主題（單字藍、句子綠、小短文紫），深色模式各有較亮版本；整頁 accent / 進度條 / 目前字高亮跟隨當前選中的挑戰色——首頁切換木馬（箭頭、圓點、拖曳、滾輪、方向鍵）整站主題立刻跟著換，進入練習頁後維持該色。
- 練習頁已刪除預設說明字串（「看上方目標字，照著打…」與「注音選字中不計分；半形標點…」），`hintLine` 僅保留英文誤入警告、未打滿換行提示、完成與新紀錄等動態回饋。
- 速度計算：單字／句子以整輪連續時間計（首題第一鍵到末題完成，含題間間隔），避免短題逐題計時膨脹；並以每字最少 0.2 秒為下限封頂 300 字/分。瞬間完成（貼上）會標「計時異常」且不計入最佳；舊版 1920 等 >450 的髒最佳會在載入時自動清除。
- 逐字判定：對綠、錯紅、目前字底線提示。
- 標點寬容：半形 `, . ! ? ; :` 與全形 `，。！？；：` 互通判定（減少 typing.tw 那種格式勒索感）。
- 速度單位：**字／分鐘**（正確字數 ÷ 分鐘）。中文站慣用此口徑；英文 WPM（5 字一詞）另算，此站不採用。
- 結算：用時、速度、正確率、答對字數、個人最佳（`localStorage`，不上傳）。
- 隨機：每模式洗牌且不連續重複上一題。

## 檔案

- `index.html` — 頁面結構（原創）
- `style.css` — 樣式
- `app.js` — 打字引擎（支援 composition 事件）
- `favicon.svg` / `favicon.png` / `favicon-32.png` / `favicon-16.png` — 瀏覽器分頁圖示（藍底白「打」，對齊左上角品牌標）
- `data.json` — 題庫
- `zhuyin.json` — 每題逐字注音對齊（離線由 pypinyin 產生，817 題）
- `cangjie.json` — 倉頡拆字字庫（41,857 字，`build_cangjie.py` 由 Jackchows/Cangjie5 `Cangjie5_TC.txt` 產生）
- `boshiamy.json` — 嘸蝦米拆字字庫（13,076 字，`build_boshiamy.py` 由 cin-tables `boshiamy.cin` 產生；速成由倉頡碼推導，無獨立字庫）
- `build_cangjie.py` — 重跑產生 `cangjie.json`（自動下載或讀本機碼表）
- `build_boshiamy.py` — 重跑產生 `boshiamy.json`（自動下載或讀本機碼表）
- `serve.py` / `serve.sh` — 靜態伺服器
